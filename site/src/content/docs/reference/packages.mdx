Every Go package in the app, one line each. Packages marked **generated** are written by a Make
target and never edited by hand; packages marked **test** are imported only by tests. Directories
that hold no Go code (`testdata/`, templates, schema files) are listed where they matter. The
dependency rule between these layers is described in
[The dependency rule](/go-clean-template/concepts/dependency-rule/).

## internal/app: wiring

| Package                   | Holds                                                                                                                                                                                                                 |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `internal/app`            | The one place everything is wired: a module per domain (`task.go`, `user.go`, …), `modules.go`, the buses (`buses.go`), the HTTP mux (`http.go`), the gRPC server (`grpc.go`), the backfill, and `Run` / `RunWorker`. |
| `internal/app/migrations` | The goose SQL migrations, embedded into the binary (`migrations.FS`).                                                                                                                                                 |

## internal/entity: the domain

| Package                      | Holds                                                                                                                                          |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `internal/entity`            | Read shapes, aggregates and their events, claims, sentinel errors and their kinds, email data, roles, paging. Imports nothing from the module. |
| `internal/entity/analytics`  | The analytics events the capture handlers send, one file per domain.                                                                           |
| `internal/entity/mongo/task` | A task's attributes (priority, estimate, labels), their rules, and `TaskWithAttributes`.                                                       |

## internal/repo: ports and their implementations

| Package                               | Holds                                                                                                                                                     |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `internal/repo`                       | The ports handlers call: `contracts.go` (event store, subscriber, checkpoints, session, limiter) and one file per domain (read model and outbound ports). |
| `internal/repo/repomock`              | **generated** (`make mock`): gomock mocks of the contracts, one file per contract file.                                                                   |
| `internal/repo/memstore`              | **test**: the in-memory event store command-handler tests use.                                                                                            |
| `internal/repo/eventstoretest`        | **test**: the contract suite every event store passes.                                                                                                    |
| `internal/repo/eventcodec`            | What every event store shares: the codec (with upcasting), the snapshot rule, claims and metadata. Its `testdata/events/` holds the frozen event samples. |
| `internal/repo/persistent/eventstore` | The Postgres event store (`events`, `snapshots`, `claims`), its reader, and the backfill.                                                                 |
| `internal/repo/persistent/projection` | The projection runner the worker runs, `NewProjector`, checkpoints, rebuilds and the lag metric.                                                          |
| `internal/repo/persistent/queries`    | **generated** (`make sqlc`): typed Go from the `.sql` query files beside it.                                                                              |
| `internal/repo/persistent/task`       | The task read model (`tasks`), its projector and importer.                                                                                                |
| `internal/repo/persistent/user`       | The user read model (`users`, `user_identities`), its projector and importer.                                                                             |
| `internal/repo/persistent/passkey`    | The passkey read model (`webauthn_credentials`), its projector and importer.                                                                              |
| `internal/repo/persistent/exchange`   | The exchange read model (`exchange_history`), its projector and importer.                                                                                 |
| `internal/repo/mongo/task`            | The task attributes store on MongoDB.                                                                                                                     |
| `internal/repo/webapi`                | Outbound HTTP: the ExchangeRate-API rate client and its cache port.                                                                                       |
| `internal/repo/limiter`               | The sign-in limiter on Valkey.                                                                                                                            |
| `internal/repo/session`               | Issues the JWT a sign-in answers with.                                                                                                                    |
| `internal/repo/ceremony`              | The WebAuthn ceremonies of passkey registration and login.                                                                                                |
| `internal/repo/ceremony/ceremonytest` | **test**: plays the browser and the authenticator.                                                                                                        |
| `internal/repo/sso`                   | The OpenID Connect sign-in ceremony (authorization code with PKCE).                                                                                       |
| `internal/repo/sso/ssotest`           | **test**: an OpenID Connect provider on `httptest`.                                                                                                       |
| `internal/repo/notify`                | Publishes emails for the worker (`repo.UserNotifier`).                                                                                                    |
| `internal/repo/mailtmpl`              | Renders email from the embedded templates in `templates/`; goldens in `testdata/`.                                                                        |
| `internal/repo/mailer`                | Delivers rendered email through `pkg/smtp`.                                                                                                               |
| `internal/repo/analytics`             | Publishes analytics events for the worker, one message per sink.                                                                                          |
| `internal/repo/analytics/posthog`     | The PostHog analytics sink.                                                                                                                               |
| `internal/repo/analytics/sinktest`    | **test**: the contract every analytics sink passes.                                                                                                       |

## internal/controller: transports

| Package                                   | Holds                                                                                        |
| ----------------------------------------- | -------------------------------------------------------------------------------------------- |

| `internal/controller/restapi/v1/task`     | v1 task operations.                                                                          |
| `internal/controller/restapi/v1/user`     | v1 sign-up, password sign-in and profile.                                                    |
| `internal/controller/restapi/v1/exchange` | v1 currency conversion and history.                                                          |
| `internal/controller/restapi/v1/passkey`  | v1 passkey sign-in and management.                                                           |
| `internal/controller/restapi/v1/oidc`     | v1 SSO status and sign-in.                                                                   |
| `internal/controller/restapi/v1/flags`    | v1 feature flags.                                                                            |
| `internal/controller/grpc/middleware`     | The gRPC interceptors: client address, log, metrics, recovery, auth.                         |
| `internal/controller/grpc/v1/rpcerr`      | `Status`: error kind to gRPC status.                                                         |
| `internal/controller/grpc/v1/response`    | Timestamps and counts as proto fields.                                                       |

| `internal/controller/worker/v1`           | Queue message handlers the worker consumes (mail, analytics).                                |

## pkg: infrastructure with no domain knowledge

| Package               | Holds                                                                                   |
| --------------------- | --------------------------------------------------------------------------------------- |
| `pkg/cqrs`            | The command and query buses, their step pipeline, and the trace, log and metrics steps. |
| `pkg/postgres`        | The pgx pool, transactions (`InTx`) and `Executor(ctx)`, traced by otelpgx.             |
| `pkg/migrate`         | Applies the embedded goose migrations.                                                  |
| `pkg/valkey`          | The Valkey client and `Cache`.                                                          |
| `pkg/mongo`           | The MongoDB client and its command tracing.                                             |
| `pkg/broker`          | NATS JetStream through Watermill: publish, consume, retries and the poison topic.       |
| `pkg/jwt`             | Signs and parses JWTs.                                                                  |
| `pkg/clientip`        | Resolves the client address, behind a trusted proxy too.                                |
| `pkg/flags`           | Feature flags through OpenFeature.                                                      |
| `pkg/flags/flagstest` | **test**: a flags client with fixed values.                                             |
| `pkg/smtp`            | Sends email over SMTP.                                                                  |
| `pkg/tracing`         | OpenTelemetry tracing with an OTLP/gRPC exporter.                                       |
| `pkg/sentrylog`       | Reports unexpected errors to a Sentry-protocol server (GlitchTip).                      |

`pkg/` never imports `internal/`.
